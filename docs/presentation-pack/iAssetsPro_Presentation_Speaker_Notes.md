# iAssetsPro Presentation Speaker Notes

## Opening (30 seconds)
“iAssetsPro is an enterprise asset management platform that connects the physical machine, its engineering hierarchy, corrective repairs, preventive maintenance, spares, tools, downtime, people and cost in one traceable system.”

## Three ideas to repeat
1. **Exact physical context:** Machine -> assembly -> subassembly -> component -> part.
2. **Governed workflow:** A defect becomes an approved work order, not an informal repair.
3. **One history:** Repairs and PM both write back to the same asset/component history.

## Live demo sequence
1. Machines -> Add Asset: show tag, serial, criticality, plant/department and parent asset.
2. Open Rotary Printing Machine 01 -> Visual Explorer: drill to Drive-End Bearing.
3. Repairs Maintenance -> Repair Requests: explain intake and conversion.
4. Repair Work Orders: show planning/assignment/execution.
5. Material Requests and Tool Requests: explain issue/return and damaged custody.
6. Completion & Closure: explain technician report and supervisor gate.
7. PM Maintenance -> PM Schedules -> New Schedule.
8. Select Rotary Printing Machine 01 -> Choose PM Target -> drill to bearing -> Confirm Selection.
9. Show time/meter frequency, PM template, auto work order and PM Calendar.

## Strong closing line
“iAssetsPro makes maintenance measurable because every request, minute, spare, tool, checklist and cost can be traced to the exact maintainable object inside the machine.”
